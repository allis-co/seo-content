## Step 5: 構造化

### 上位概念
検索者の課題は「Microsoft広告に取り組むべきか → 取り組むなら誰に頼むか」の2段階の意思決定。

### 分岐構造

```
Microsoft広告を検討中
│
├─ 第1の判断: そもそも取り組むべきか？
│  ├─ 有力なケース
│  │  ├─ 既存媒体（Google/Yahoo!）のCPCが高騰している
│  │  ├─ BtoB商材・PCユーザーが主要ターゲット
│  │  └─ 追加媒体の予算を月20〜30万円以上確保できる
│  └─ 優先度が低いケース
│     ├─ 既存媒体にまだ伸びしろがある
│     ├─ モバイルアプリ・若年層がメインターゲット
│     └─ 追加の予算余力がない
│
├─ 第2の判断: 誰に頼むか？
│  ├─ 既存代理店にMicrosoft広告も任せる
│  │  ├─ メリット: 情報集約・アカウント統合管理
│  │  └─ リスク: Microsoft広告のノウハウが浅い可能性
│  ├─ Microsoft広告に強い代理店を別途探す
│  │  ├─ メリット: 専門性の高い運用
│  │  └─ リスク: 代理店間の連携コスト
│  └─ 自社で運用する
│     ├─ Google広告インポート機能で導入は比較的容易
│     └─ リスク: 最適化のノウハウ不足
│
└─ 第3の判断: 代理店をどう選ぶか？（Microsoft広告固有の選定軸）
   ├─ ノウハウの深さ（後発媒体ゆえの差が大きい）
   ├─ LinkedInプロフィールターゲティングの活用実績
   ├─ Google広告インポート後の最適化プロセス
   ├─ 担当社数と優先度（追加媒体で予算が小さいと放置されるリスク）
   └─ アカウント所有権・移管ポリシー
```

### 優先順位・判断軸
- **最重要**: 「やるべきか」の判断が先。代理店選びは後。多くの競合記事はこの順序を無視して「おすすめ代理店」から入っている
- **Microsoft広告特有の判断軸**: 既存代理店との関係性をどう整理するかが、Google広告の代理店選びとの最大の違い。ほとんどの読者はゼロからの代理店探しではなく、既存の運用体制にMicrosoft広告をどう組み込むかが課題
- **予算の現実**: Microsoft広告は追加媒体として始めることが多く、月額予算が小さくなりがち。手数料20%の場合、月額広告費50万円でも手数料は10万円。代理店のビジネスモデル上、少額案件は優先度が下がるリスクがある（knowledgeカード001参照）
